# BIBS
BIBSS is a deterministic, edge-canonical, zero-network structural inference engine that takes CSV or JSON bytes and produces a byte-identical Canonical Internal Schema Model (CISM) describing the input's shape — types, nesting, optionality — without interpreting field names or value semantics.

**Try it:** [skreen5hot.github.io/BIBS](https://skreen5hot.github.io/BIBS/) — an in-browser playground (deployed by `.github/workflows/pages.yml` on every push to `main`, after the test suite passes).

## Build status — complete autonomous build (15/15 modules)

`src/` and `test/` here were generated by the **IntegratedAgent autonomous build loop** (contained in
a `docker --network=none` sandbox, judged, under a recorded §3.4 grant) from `BIBSS-V1.3-SPEC.md`, as
a scale test of that loop. **All 15 planned modules are built** — the leaf modules (input detection,
JSON/CSV normalization + narrowing, the §8 inference primitives: lattice widening, property-merge,
array inference, cross-kind union, type-distribution; sampling; the adapter registry) **and the
integration tail**: the composing inference engine (M10), the JSON-Schema / CISM output adapters
(M13/M14), and the public `infer()` API (M15) — with **928 passing test assertions**
(`node test/run.mjs`).

```js
import { BIBSS } from "./src/bibss.mjs";
const { cism, diagnostics } = BIBSS.infer('[{"a":1,"b":"x"},{"a":2,"b":null}]');
const jsonSchema = BIBSS.project(cism, "jsonschema");   // CISM -> JSON Schema Draft 2020-12
```

**Crossing the composition ceiling.** An earlier run stalled at 11/15: the composing engine (M10)
reimplemented a dependency instead of importing it, bloating the dispatch past the time limit. The
loop was taught to give each module its dependencies as **interfaces** (exported signatures, not
implementation) and to fail reimplementation with a **mechanical gate** ahead of the judge — so M10
built on the first attempt within the same dispatch envelope, importing its primitives rather than
reinventing them. See ADR-013 in the IntegratedAgent repo.

[`vendor/PROVENANCE.md`](vendor/PROVENANCE.md) for the one vendored dependency (Papa Parse, pinned +
hashed). Build provenance and findings: ADR-012 (the scale finding) and ADR-013 (the crossing).
