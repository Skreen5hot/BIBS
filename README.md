# BIBS
BIBSS is a deterministic, edge-canonical, zero-network structural inference engine that takes CSV or JSON bytes and produces a byte-identical Canonical Internal Schema Model (CISM) describing the input's shape — types, nesting, optionality — without interpreting field names or value semantics.

## Build status — partial autonomous build (11/15 modules)

`src/` and `test/` here were generated by the **IntegratedAgent autonomous build loop** (contained in
a `docker --network=none` sandbox, judged, under a recorded §3.4 grant) from `BIBSS-V1.3-SPEC.md`, as
a scale test of that loop. **11 of 15 planned modules are built** — the leaf modules (input
detection, JSON/CSV normalization + narrowing, the §8 inference primitives: lattice widening,
property-merge, array inference, cross-kind union, type-distribution; sampling; the adapter registry)
— with **631 passing test assertions** (`node test/run.mjs`).

**Not yet built (the integration tail):** the composing inference engine (M10), the JSON-Schema /
CISM output adapters (M13/M14), and the public `infer()` API (M15). **So there is no assembled
entry point yet — this is a working set of components, not a finished tool.** The build stalled at the
composition module (the model reimplemented a dependency instead of importing it).

See [`BUILD-METRICS.md`](BUILD-METRICS.md) for the full per-module/per-run metrics and
[`vendor/PROVENANCE.md`](vendor/PROVENANCE.md) for the one vendored dependency (Papa Parse, pinned +
hashed). Build provenance and findings: ADR-012 in the IntegratedAgent repo.
